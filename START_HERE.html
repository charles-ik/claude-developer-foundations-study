Want the AI study partner?

Install Python 3.10 or later, then double-click Open Study Studio.command on macOS or Open Study Studio.bat on Windows in this folder. The launcher opens the studio in your default browser. On Linux, run python3 practice_server.py --open.

Keep the terminal open while studying. Add your own API key in tutor settings. Tests and answer explanations also work without a key.

Pick up where you left off.

Your answers, flags, and session history stay in this browser on this computer. Reopen using the same method, browser profile, and address, then select Resume session. For regular use, use the launcher each time; it keeps a consistent local address.

Private browsing, clearing browser data, changing ports, or switching between offline files and the local server can hide or remove saved progress. Nothing is uploaded or synced between devices.

See the repository’s README.md for complete setup instructions and troubleshooting.
